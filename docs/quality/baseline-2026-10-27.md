## Findings that need action now

**F1 — Critical advisories in the website's `next` (security gate fails today).**
The gate exits 1 on three advisories that are not in
`.github/security/known-findings.json`:

| Advisory | Severity | Title |
|---|---|---|
| GHSA-2464-fhr4-w9xw | critical | Unauthenticated Remote Code Execution in Image Optimization API when SVG files are used |
| GHSA-673q-mjm6-r5xr | critical | Unauthenticated Remote Code Execution in `use cache` functions returning typed arrays |
| GHSA-p3m5-59mp-jv5r | high | Denial of Service in App Router using Server Actions |

`npm audit` reports the fix as `next@16.4.3`. The next pull request into
`rebuild/dotnet-platform` will have a red Security workflow until this is fixed.
Under the standard (section 8), a critical or high finding is fixed within 7
days of being known, reachable or not, or the owner records an exception with
an expiry. The production site is a static export, which limits reachability;
that is a reason for an exception, not a substitute for one.

**F2 — The weekly security scan has never run.** `security.yml` and
`codeql.yml` have `schedule:` triggers, but GitHub runs scheduled workflows only
from the default branch. The default branch is `main`, which has no workflows.
`list_workflow_runs` with `event=schedule` returns 0 runs. So the full-history
secret scan and the dependency audits run only when someone pushes to the rebuild
branch or opens a pull request; F1 was found by this measurement, not by CI.

**F3 — Three known High findings are past the 7-day deadline.** The website
entries in `known-findings.json` (`next` SSRF GHSA-cjq9-62q9-8jv4, `sharp`
GHSA-wq5f-xc86-pv6w, `source-map-js` GHSA-68fv-2mgg-jv7q) were recorded on
2026-10-13 with an owner and a reason, but no expiry and no owner decision.
`next@16.4.3` also fixes the first; `npm audit` reports fixes for the other two.

**F4 — Development dependencies are not audited.** The gate runs
`npm audit --omit=dev`. A full-tree audit adds, for the website: `vite` (high),
`undici` (high), `vitest` / `@vitest/mocker` (moderate), `fast-uri` (moderate);
for the Studio: `vite` (high, direct), `undici` (high), `source-map-js` (high),
`vitest` (moderate). The standard audits the full tree, including dev, because
the build machine runs these.

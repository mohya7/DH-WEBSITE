# @digitalhub/theme

Shared Studio tokens for Phase G. CSS variables, TypeScript constants, and the Digital Hub wordmark.

The website does not import this package. `#1270A0` stays the website primary. The Studio accent `#45A8D4` and the near-black action fill are for product UIs (Studio now, hiring later), not for the public site.

Import `tokens.css` for variables and `:focus-visible`. Import the module for the same values in TypeScript. The logo is `./logo.png`.

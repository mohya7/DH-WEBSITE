# @digitalhub/theme

Shared tokens for the website and the Studio. CSS variables, TypeScript constants, and the Digital Hub wordmark.

The website does not import this package. `#1270A0` stays the website primary. The Studio accent `#45A8D4` and the near-black action fill are for the Studio, not for the public site.

Import `tokens.css` for variables and `:focus-visible`. Import the module for the same values in TypeScript. The logo is `./logo.png`.
